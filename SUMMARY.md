# Aurum Blender MCP

An MCP server and a Blender add-on that let an AI agent model in Blender:
build geometry, assign materials, render previews, export glTF.

[![CI](https://github.com/AG064/blender-mcp/actions/workflows/ci.yml/badge.svg)](https://github.com/AG064/blender-mcp/actions/workflows/ci.yml)

Any MCP client can drive it. The agent does not have to be a particular one.

```powershell
pwsh -File install.ps1
```

Read [README.md](README.md) for the full story — installing it, pointing an
agent at it, the tool list, and how the two halves fit together.
